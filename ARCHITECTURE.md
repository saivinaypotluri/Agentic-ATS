### AI Agents Layer

#### 1. Resume Parser Agent

**Purpose**: Extract structured data from resumes

**Technologies**:
- PyMuPDF (PDF parsing)
- python-docx (DOCX parsing)
- Regular expressions (entity extraction)

**Process**:
1. Accept file upload
2. Extract raw text based on file type
3. Parse entities (name, email, phone)
4. Extract skills using keyword matching
5. Identify education and experience sections
6. Store structured data in database

#### 2. Job Match Agent

**Purpose**: Compute semantic similarity between resume and job description

**Technologies**:
- SentenceTransformers (all-MiniLM-L6-v2)
- Scikit-learn (cosine similarity)

**Algorithm**:
```python
1. Load pre-trained transformer model
2. Generate embeddings for resume text
3. Generate embeddings for job description
4. Compute cosine similarity
5. Scale to 0-100 range
6. Fallback to keyword matching if model unavailable
```

**Performance**:
- Model size: ~80MB
- Inference time: ~100-500ms
- Accuracy: Based on sentence-transformers benchmarks

#### 3. Profile Intelligence Agent

**Purpose**: Enrich candidate profiles with external data

**Data Sources**:

| Source | Method | Data Extracted |
|--------|--------|----------------|
| GitHub | REST API | Repos, languages, followers, bio |
| LinkedIn | Mock (OAuth required) | Headline, experience, skills |
| Other URLs | Web scraping | Title, description, metadata |

**Process**:
1. Detect URLs in resume
2. Classify by platform (LinkedIn, GitHub, misc)
3. Fetch data from each source
4. Apply rate limiting (0.5s between requests)
5. Generate human-readable summary
6. Store enriched data as JSON

#### 4. Scheduler Agent

**Purpose**: Suggest and manage interview schedules

**Features**:
- Generate next 5 business day slots
- Validate business hours (9 AM - 5 PM)
- Skip weekends
- Calendar invite generation

**Algorithm**:
```python
1. Start from tomorrow
2. For each day:
   - Skip if weekend
   - Generate morning slot (10:00 AM)
   - Generate afternoon slot (2:00 PM)
3. Return first N valid slots
```

#### 5. Feedback Agent

**Purpose**: Process and summarize interview feedback

**Capabilities**:
- Extract ratings (1-5 scale)
- Identify strengths and weaknesses
- Sentiment analysis
- Generate structured summaries

**NLP Techniques**:
- Keyword extraction
- Pattern matching
- Section detection
- Rating inference

## Security Considerations

### Current Implementation

1. **CORS**: Configured to allow all origins (development)
2. **File Upload**: Validates file extensions
3. **SQL Injection**: Protected via SQLAlchemy ORM
4. **XSS**: React escapes content by default

### Production Recommendations

1. **Authentication**:
   - Implement JWT-based auth
   - Add user roles (recruiter, admin)
   
2. **Authorization**:
   - Protect endpoints with decorators
   - Implement role-based access control

3. **File Upload**:
   - Scan for malware
   - Limit file size (10MB max)
   - Validate MIME types

4. **API Rate Limiting**:
   - Use slowapi or similar
   - Limit requests per IP/user

5. **HTTPS**:
   - Use SSL/TLS in production
   - Secure cookie flags

6. **Environment Variables**:
   - Store secrets in .env
   - Never commit .env to git

## Scalability Considerations

### Current Limitations

- SQLite (single-file database)
- In-memory model loading
- Synchronous processing

### Scaling Strategies

1. **Database**:
   - Migrate to PostgreSQL
   - Implement connection pooling
   - Add read replicas

2. **AI Models**:
   - Use model caching
   - Deploy models as separate service
   - Consider GPU acceleration

3. **Background Jobs**:
   - Use Celery + Redis
   - Async processing for long tasks
   - Queue-based architecture

4. **Caching**:
   - Redis for API responses
   - Cache embeddings
   - CDN for frontend assets

5. **Load Balancing**:
   - Multiple FastAPI instances
   - Nginx reverse proxy
   - Auto-scaling (K8s)
